privacy policy

moodshuffle · stupidhimbo

Effective October 15, 2026

About this project

Moodshuffle is a visual inspiration project operated by StupidHimbo at stupidhimbo.com. This policy covers /moodshuffle/ and its privacy page, not other tools on this domain. The project is currently a static preview. Pinterest authorization, automatic board access and image draws are not active.

What the preview collects

These pages do not ask you to register, submit personal information or connect a Pinterest account. They do not use application cookies, local storage, advertising trackers or analytics scripts. We do not currently receive Pinterest account data through these pages.

The site is hosted on GitHub Pages. GitHub may process technical request information, including IP addresses, for hosting, security and service operation under its privacy statement. The pages load fonts from Google Fonts, which receives technical request information such as your IP address and browser details; see Google Fonts privacy information.

Planned Pinterest connection

If approved and enabled, the integration is intended to read a board selected by the authorized account owner and display a randomly selected image Pin with a link back to Pinterest. Visitors would not need to connect their own accounts to browse the collection.

We intend to request only the permissions required to read boards and Pins. We will not request Pinterest passwords, publish or change Pins, or use Pin content to train AI models. We do not plan to create a permanent external archive of Pinterest images or Pin metadata.

This preview does not yet implement credential storage or a backend. Before authorization is enabled, this policy will be updated to explain the actual data collected, authorization-token handling, service providers, retention, account disconnection and deletion procedures. Connecting an account will require Pinterest’s own authorization flow.

Sharing and external links

We do not sell personal information or share Pinterest API data with advertising services. Following a link to Pinterest, GitHub or another website takes you to a service governed by its own policies. Pinterest’s privacy policy applies when you use Pinterest.

Retention and your choices

The preview maintains no visitor account database or Pinterest data archive. Hosting and font providers apply their own retention policies. You can browse without connecting an account. If you contact us by email, we use your message and address to respond and handle the request; you can ask us to delete that correspondence, subject to any legal retention obligations.

Contact and changes

For privacy questions, access or deletion requests, email yarrow-hermes-agent@agentmail.to, the project contact inbox. We will update the effective date when this policy changes and revise it before introducing new data collection.
